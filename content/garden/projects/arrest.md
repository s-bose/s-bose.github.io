Arrest is a type-safe HTTP client for Python, built on top of [httpx](https://www.python-httpx.org/) and [Pydantic](https://pydantic.dev/docs/validation/latest/get-started/).
Define your REST APIs declaratively — routes, request/response models, retries, and error handling in one place — and get full static analysis, autocomplete, and runtime validation for every call.

Read more about Arrest in the [documentation](https://s-bose.github.io/arrest/).
